# Tree House Cafe 🌲☕

الموقع الرسمي والمنيو الرقمي التفاعلي لـ **Tree House Cafe** (تري هاوس كافيه) — البدرشين، الجيزة.

> **"Where every cup feels like home"** — **Good Vibes. Great Coffee.**

---

## 🌟 مميزات المشروع

- **تصميم واقعي فريد (Warm Botanical & Architectural):** مستوحى من واجهة المحل الحقيقية (الصاج الأخضر المعماري `#0D261C`، الإضاءة الكهرمانية الدافئة `#D49B4B`، وورق المنيو الطبيعي `#F4EFE6`).
- **منيو رقمي متكامل (75 صنفاً):** جرد كامل وموثق لجميع أصناف الكافيه موزعة على 9 تصنيفات دقيقة:
  - Coffee (17 صنفاً)
  - Hot Beverages (10 أصناف)
  - Iced Coffee (6 أصناف)
  - Frappe (3 أصناف)
  - Milkshakes (8 أصناف)
  - Fresh Juice & Smoothies (7 أصناف)
  - Soft Drinks & Energy (19 صنفاً)
  - Desserts (3 أصناف)
  - Mineral Water (صنفان)
- **بحث فوري وفلترة ذكية:** بحث سريع بالعربي والإنجليزي، وفلترة حسب درجة الحرارة (ساخن / مثلج)، وتبويب أقسام أفقي لاصق على الموبايل.
- **قائمة طلبي (Order Summary Drawer):**
  - حفظ اختيارات العميل محلياً.
  - إرسال الطلب مباشرة بنقرة واحدة عبر واتساب برسالة منسقة بالكامل مع رقم الطاولة والملاحظات.
  - وضع شاشة النادل (Waiter Mode) لعرض الطلب بوضوح على الطاولة.
- **الموقع وساعات العمل والتواصل:**
  - العنوان الدقيق: "الجيزة - البدرشين الطريق السريع بجوار فيلا شريف عناني".
  - ربط مباشر بخرائط جوجل (Google Maps)، فيسبوك، إنستجرام (@tree_house_caffe)، وواتساب.
- **أداء عالي وسرعة فائقة:** جاهز للنشر الفوري على Vercel عبر `vercel.json` وتوافق تام 100% مع الهواتف ومسح QR Code الطاولات.

---

## 🛠️ التقنيات المستخدمة

- **React 18** + **TypeScript**
- **Vite** (أداء وبناء فائق السرعة)
- **Tailwind CSS** (نظام تصميم صارم مخصص)
- **Lucide React** (أيقونات واضحة وخفيفة)
- **Google Fonts:** Cairo + IBM Plex Sans Arabic + Fraunces

---

## 🚀 التشغيل محلياً

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء حزمة الإنتاج
npm run build
```
