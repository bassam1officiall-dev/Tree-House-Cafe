# Tree House Cafe

موقع ومنيو رقمي لكافيه Tree House في البدرشين، الجيزة.

## التشغيل والتطوير

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## تعديل البيانات

- تعديل الأصناف والأسعار: من خلال الملف `src/data/menu.ts`.
- تعديل العنوان ورقم الواتساب وساعات العمل: من خلال الملف `src/config/site.ts`.
- إعدادات النشر على Vercel: من خلال الملف `vercel.json`.

## البنية التقنية

- React 18
- TypeScript
- Vite
- Tailwind CSS
